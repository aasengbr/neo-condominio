# NEO_Condomínio — app do síndico (PWA v0)

Registro de ocorrências, compromissos e gastos do condomínio: foto, vídeo, voz (com transcrição) e texto, direto do celular. Banco local no aparelho; exportação/importação para a planilha Google "NEO_Condominio — Gestao" via Apps Script (`Code.gs`).

Projeto e regras: Drive › NEO_Condominio › "Projeto do Aplicativo (05-11-2026)".

## Instalar no celular (Chrome Android)
1. Abrir a URL do GitHub Pages deste repositório.
2. Menu ⋮ → Instalar app (ou Adicionar à tela inicial).
3. Na primeira foto/voz, aceitar câmera, microfone e localização.

## Retaguarda (Agnaldo)
Toque longo no título → tela Planilha: URL do Apps Script, Enviar para a planilha, Atualizar cadastros, Importar conversa do WhatsApp.
